# Contributing to QuanuX

Thank you for your interest in contributing to QuanuX! We welcome feedback, improvements, and participation in ways that align with the project’s goals and current focus.

This document explains how you can contribute in a helpful and efficient way.

---

## How to Get Started

1. **Open an Issue**  
   If you have a bug report, suggestion, or question, open a new GitHub issue with a descriptive title and details.

2. **Discuss Before Major Changes**  
   For larger features or architecture changes, start a discussion in issues first so reviewers can provide early feedback.

3. **Fork & Branch**  
   Fork the repository and create a feature branch from `main`:
   ```bash
   git checkout -b your-feature-name
   ```

4. **Make Your Changes**  
   - Follow existing code style
   - Add tests where appropriate
   - Keep descriptions clear

5. **Submit a Pull Request**  
   Open a pull request describing:
   - What change you made
   - Why it’s valuable
   - Any outstanding questions

---

## Tips for Successful Contributions

- Keep changes scoped and incremental.
- Run any existing tests to ensure your change doesn’t break current behavior.
- Documentation updates are always welcome!
