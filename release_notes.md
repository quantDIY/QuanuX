## QuanuX v0.0.1-pre

This is the **initial public pre-release** of **QuanuX**.

This release establishes the public baseline for the project as it transitions from private development to early public visibility.

---

### ⚠️ Pre-Release Notice

QuanuX is currently in **active development** and should be considered **experimental**.

- APIs, schemas, and internal interfaces may change
- Backward compatibility is **not guaranteed**
- Features may be incomplete or unstable
- This release is **not production-ready**

---

### 🧱 What’s Included

- Core repository structure for the QuanuX platform
- Client and server scaffolding
- Desktop and web application shells
- Canonical schema authority and tooling foundations
- Canonical tool authority (MCP) foundations
- Development tooling, CI scaffolding, and devcontainer support
- Public README with Quickstart and setup guidance
- Community health files (contributing, conduct, support)

---

### 🚀 Getting Started

See the project README for:
- Quickstart instructions
- Development environment setup
- Manual and Anaconda-based installation paths
