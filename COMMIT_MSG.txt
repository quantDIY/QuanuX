refactor(runtime): Pivot Orchestration Nucleus to C++20

Replaced the initial Python prototype of the Server Runtime with a high-performance C++20 implementation.

## Changes
*   **Removed**: `server/runtime/main.py`, `bus.py`, `bootstrap.py`.
*   **Added**: `server/runtime/src/supervisor.cpp` (C++ NATS Wrapper).
*   **Added**: `server/runtime/CMakeLists.txt` (Builds `quanux_supervisor` with `nats.c`).

## Capabilities
*   **Native Bootstrapping**: The Supervisor now uses the NATS C client to automatically provision the JetStream taxonomy (MARKET, ORDER, EXEC, SYS) on startup.
*   **Zero Overhead**: Orchestration now shares the same memory model and performance characteristics as the Execution Nodes.
*   **Unified Stack**: The entire critical path (Indicators -> Supervisor -> Execution) is now pure C++.
