feat(control): Add Python Control Plane for C++ Runtime

Implemented a lightweight Python client (`quanux.runtime`) to drive the C++ Supervisor.

## Features
*   **RuntimeClient**: A NATS JetStream wrapper that publishes commands (e.g., `sys.cmd.spawn`) and subscribes to telemetry.
*   **Decoupling**: Allows the Python Strategy Builder / UI to control the organism without linking against C++ binaries.
*   **Verification**: Included `verify_control.py` to prove end-to-end connectivity.
