# Python Wrappers for Native Extensions

This directory will contain Python wrappers for the C++ extensions. 
The goal is to use `ctypes` or `pybind11` to expose the C++ performance layer to the Python-based execution engine.

## Structure
- `rithmic/`: Wrapper for Rithmic C++ extension.
- `ibkr/`: Wrapper for IBKR C++ client.
