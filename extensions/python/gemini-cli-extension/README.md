# QuanuX Gemini CLI Extension

This extension integrates the **QuanuX Algorithmic Trading Platform** with the **Gemini CLI**.

## Capabilities
-   **Context Aware**: Automatically loads `GEMINI.md` so the agent understands QuanuX architecture (C++ Priority, Mobile Ecosystem).
-   **Strategy Generation**: `/quanux:generate` creates full Python strategy packages in `server/strategies/`.
-   **System Status**: Checks the health of the Runtime Engine.

## Installation

1.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Link Extension**:
    From this directory, run:
    ```bash
    gemini extensions link .
    ```

3.  **Verify**:
    Restart Gemini CLI and run:
    ```bash
    /quanux:generate "Mean reversion on NQ"
    ```

## Code Generation & Web UI
Strategies generated by this extension are written to `server/strategies/`. They are immediately visible in the QuanuX Web/Desktop UI under the "Strategies" tab, allowing for seamless transition from CLI generation to visual editing.
