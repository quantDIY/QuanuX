# Security Policy

## Supported Versions

As this project is in an early **pre-release** stage (`v0.0.1-pre`), we currently support security updates for:

| Version | Supported          |
| ------- | ------------------ |
| v0.0.x  | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please do NOT create a public GitHub issue.

### Process

1.  **Email**: Send details to `security@quanux.org` (or the project maintainer directly).
2.  **Response**: We will acknowledge your report within 48 hours.
3.  **Resolution**: We will work to verify and resolve the issue. Once patched, we will coordinate a public disclosure if appropriate.

### What to Include

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

Thank you for helping keep QuanuX secure.
